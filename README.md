# yotils

A Python utility library.

## Installation

```bash
pip install yotils
```

## Usage

```python
import yotils
print(yotils.__version__)
```

## Development

This project uses `uv` for dependency management and `hatchling` as the build backend.

### Building

```bash
uv build
```

### Installing from source

```bash
pip install -e .
```
